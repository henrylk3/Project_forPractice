# 智能聊天机器人 - 用户使用手册

## 简介

智能聊天机器人是一款基于深度学习技术的微信小程序应用，能够理解你的需求并提供智能回复。它支持多轮对话、上下文理解，并可根据你的偏好调整对话风格。

## 快速开始

### 1. 登录

- 打开小程序后，点击"微信一键登录"按钮
- 授权微信账号信息即可完成登录
- 开发环境可使用"开发模式登录"

### 2. 开始对话

- 登录后自动进入聊天界面
- 在底部输入框输入你想问的问题
- 点击"发送"按钮或按回车键发送消息
- AI助手会自动回复你的消息

### 3. 快捷操作

首次进入聊天界面时，会显示快捷操作按钮：
- 💡 解释概念 - 让AI帮你解释某个概念
- 💻 编写代码 - 让AI帮你写代码
- 📖 讲个故事 - 让AI给你讲故事
- 🌤️ 聊聊天 - 和AI闲聊

## 功能详解

### 消息类型

支持以下消息类型：
- **文本消息**: 直接输入文字发送
- **表情消息**: 点击输入框旁的表情按钮选择表情
- **图片消息**: 点击相机按钮选择或拍摄图片

### 消息状态

发送的消息会显示以下状态：
- **发送中**: 消息正在发送
- **已发送**: 消息已成功发送到服务器
- **已读**: AI已读取并回复
- **发送失败**: 发送失败，可重新发送

### 输入提示

输入文字时，系统会自动显示输入提示，点击即可快速发送。

### 对话管理

#### 查看历史对话
- 点击底部"历史"标签页
- 查看所有历史对话记录
- 点击对话可继续聊天

#### 搜索对话
- 在历史页面点击搜索栏
- 输入关键词搜索对话内容
- 搜索结果会高亮显示匹配内容

#### 删除对话
- 在历史页面长按对话
- 确认删除即可

### 个性化设置

#### 机器人角色
在设置页面可选择不同角色：
- 🤖 **智能助手**: 通用型助手，帮助解决各类问题
- 👨‍🏫 **耐心老师**: 善于用简单方式解释复杂概念
- 🤝 **友好伙伴**: 善于倾听和陪伴
- 💡 **创意达人**: 善于提供新颖想法和灵感

#### 对话风格
- 😊 **亲切友好**: 温暖亲切的交流方式
- 👔 **正式专业**: 严谨专业的表达方式
- 😄 **幽默风趣**: 轻松愉快的聊天风格
- ⚡ **简洁精炼**: 直奔主题的沟通方式

### 帮助中心

在设置页面点击"帮助中心"可查看：
- 常见问题解答
- 使用指南
- 联系方式

## 常见问题

**Q: 消息发送失败怎么办？**
A: 请检查网络连接。消息会自动缓存，网络恢复后自动重发。

**Q: 如何切换机器人角色？**
A: 进入"我的"→ 选择"机器人角色"→ 选择喜欢的角色。

**Q: 对话数据安全吗？**
A: 所有对话数据加密存储，不会分享给第三方，可随时删除。

**Q: 支持哪些消息类型？**
A: 目前支持文本、表情和图片消息。

**Q: 如何清除缓存？**
A: 进入"我的"→ 点击"清除缓存"。

## 使用技巧

1. **明确提问**: 提问越具体，AI回答越准确
2. **多轮对话**: AI支持上下文理解，可以进行连续追问
3. **角色切换**: 不同角色适合不同场景，按需切换效果更佳
4. **搜索功能**: 利用搜索功能快速找到历史对话
5. **输入提示**: 善用输入提示功能，快速表达意图

## 隐私与安全

- 所有对话数据加密存储
- 不会将对话内容分享给第三方
- 支持随时删除对话记录
- 用户输入经过安全过滤，防止恶意攻击
- 定期备份用户数据，保障数据安全
